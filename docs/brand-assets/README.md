# Kerb brand assets

Master artwork supplied by the operator on 25 Sep 2026. The site uses vector traces of the mark and wordmark (`apps/web/src/lib/brand.ts`) so they stay sharp and follow the theme; these files are the source.

| File | Use |
|---|---|
| `kerb-mark.svg`, `kerb-mark-light.png`, `kerb-mark-dark.png` | The mark alone: favicon, app icon, avatars (the OKX.AI agent avatar is `kerb-mark-dark.png`) |
| `kerb-wordmark.svg`, `kerb-wordmark-light.png`, `kerb-wordmark-dark.png` | The KERB wordmark: navigation, footer, the large footer word |
| `kerb-lockup-light.png`, `kerb-lockup-dark.png` | Mark and wordmark together |
| `kerb-banner-light.png`, `kerb-banner-dark.png` | 16:9 banner: README header (`docs/media/kerb-banner-*.webp`), social posts |
| `kerb-poster-light.png`, `kerb-poster-dark.png` | 4:3 poster artwork |

Mark: two offset slabs, the upper one full ink, the lower one a tone lighter (42% on light grounds, 60% on dark).
