## 1:37 to 2:05 - Hero sequence: Last Call and Cure

Primary source:
`06_LAST_CALL_AND_CURE.mov.mp4`

Fallback:
Use `06b...mp4` only for a cleaner transition shot or state label if 06 lacks it. Never replace a successful primary Cure with a weaker fallback just because 06b is shorter.

Visual order:
1. Session Max position still open
2. rail crosses into Last Call
3. `Curable now` appears
4. required repay or target becomes visible
5. second wallet or unrelated wallet cures
6. transaction confirms
7. position returns toward Carry or curable obligation disappears
8. fixed liquidation threshold remains unchanged if visible

Motion:
This sequence gets the film's only strong structural transition. Use the Kerb seam or rail language. One low audio impact at the exact state change. No dramatic crypto effects.

Narration:
Last Call opens before the weak session. Only the excess above Carry becomes curable. A second wallet can repair that difference and earn the bonus. This is not a full liquidation, and the liquidation threshold never moves.

Purpose:
This is the hero moment. Protect it.
