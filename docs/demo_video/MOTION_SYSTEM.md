# Motion System

## Principle

Kerb motion should feel like infrastructure changing state.

Do not decorate the product. Reveal its logic.

## Core motif: the controlled seam

Use one thin line or seam that can:
- mark a session boundary
- travel across a frame as a transition
- separate current state from next state
- create a crop reveal
- stop at a precise data point

This is the motion analogue of the Kerb identity.

## Timing language

Fast UI actions:
120 to 180 ms.

Editorial text or rule reveal:
250 to 420 ms.

Major Last Call state change:
450 to 650 ms.

Do not use elastic easing, bounce, overshoot, or playful spring motion.

Preferred easing:
smooth cubic ease in and out with restrained acceleration.

## Allowed treatments

- slow 3 to 6 percent push-in on static UI
- controlled pan to the exact data region
- crop reveal
- seam wipe
- thin rule expansion
- small opacity fade
- one muted brass highlight at a state transition
- brief split screen when connecting source measurement to resulting term
- magnified crop of a transaction confirmation
- subtle background defocus behind one critical UI region

## Forbidden treatments

- neon glow
- fake depth-of-field over readable UI
- particle fields
- coin or token animation
- glitch
- scan lines
- fake terminal rain
- holograms
- generic blockchain nodes
- parallax that distorts the UI
- excessive motion blur
- fake mouse interactions

## Scene-specific motion

Cold open:
One slow push and one thin seam.

Board:
One crop that moves from clock state to executable capacity.

Asset:
A single measurement path: pool depth -> cross-check -> resulting term.

KTS:
A clean horizontal rail showing:
NOW -> LAST CALL -> WEAK MARKET

This can be an editorial overlay, but it must not show fake timings or numbers.

Borrow:
Use a subtle emphasis around Session Max and the pre-signing preview.

Last Call:
This is the only high-energy moment. The seam crosses the rail at the exact state change, then stops. Add one low structural sound.

Proof:
Use exact-fit motion. Inputs, recompute, chain result. No dramatic effects.

Consumers:
Use clean cuts between agent and contract. A small label can read:
`ONE TERM. MULTIPLE CONSUMERS.`

Research:
No theatrics. Let the data feel serious.

Close:
Return to a calm composition. Music may open slightly after the final spoken line.
